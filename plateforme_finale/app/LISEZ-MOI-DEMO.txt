DEMONSTRATION - Plateforme de gestion des stages PFA/PFE, EIGSI Casablanca
==========================================================================

POUR LANCER LA DEMO
  1. Python 3.10 ou plus recent doit etre installe (https://www.python.org/downloads/ :
     cocher "Add python.exe to PATH").
  2. Double-clic sur  LANCER_LA_DEMO.bat
     (premier lancement : 2 a 5 minutes, Internet necessaire ; ensuite quelques secondes, sans Internet).
  3. Le navigateur s'ouvre sur http://localhost:8000/
  4. Pour arreter : fermer la fenetre noire.

ASTUCES
  - Changer de compte vite : ouvrir une fenetre de navigation privee.
  - Fichier de scan pret pour la demo : exemples\scan_convention_exemple.pdf
  - Repartir de zero apres des essais : supprimer demo.sqlite3, puis relancer LANCER_LA_DEMO.bat
  - Page blanche ou ancien aspect : Ctrl + F5.

ASSISTANT IA (facultatif)
  - Sans cle : l'assistant (bulle en bas a droite) et la relecture du sujet marchent en "mode demonstration".
  - Pour la vraie IA (Gemini) :
      1. Se connecter avec un compte Google sur https://aistudio.google.com/apikey et creer une cle API (gratuit).
         Toute cle Gemini convient : celle de Walid, la votre, ou celle d'un autre compte.
      2. Creer un fichier texte nomme EXACTEMENT  cle_gemini.txt  dans CE dossier, a cote de manage.py et de
         LANCER_LA_DEMO.bat (le dossier qui contient ce fichier LISEZ-MOI). Il ne contient qu'une ligne : la cle.
      3. Fermer la fenetre noire s'il y en a une, puis relancer LANCER_LA_DEMO.bat.
    Internet est alors necessaire. Supprimer ce fichier apres la presentation. Ne saisir que des donnees fictives.
  - PIEGE FREQUENT : Windows cache les extensions. Un fichier cree avec le Bloc-notes peut s'appeler en realite
    cle_gemini.txt.txt et ne sera pas lu. Dans l'Explorateur : onglet "Affichage" > cocher "Extensions de noms
    de fichiers", puis verifier que le nom est bien cle_gemini.txt.
  - La cle est personnelle : elle n'est jamais dans le depot GitHub (le fichier est ignore par Git). Ne la partagez pas.
